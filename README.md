# Online Retail Sales – Exploratory Data Analysis (EDA)

## Project Overview

Performed Exploratory Data Analysis (EDA) on the Online Retail dataset using Python to analyze sales trends, product performance, country-wise revenue, transaction patterns, and data quality issues.

## Objectives

- Understand the structure and characteristics of retail transaction data.
- Identify missing values, duplicate records, and data quality issues.
- Analyze revenue distribution, product performance, and country-wise sales.
- Examine monthly sales trends and transaction patterns.
- Explore numerical variables using statistical analysis and correlation.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data loading and dataset inspection
- Data cleaning and duplicate removal
- Missing-value analysis and handling
- Descriptive statistical analysis
- Revenue calculation using Quantity and UnitPrice
- Monthly revenue trend analysis
- Country-wise revenue analysis
- Top 10 product revenue analysis
- Country-wise unique customer analysis
- Data visualization using:
  - Line plots
  - Bar charts
  - Histograms
  - Boxplots
  - Scatter plots
  - Correlation heatmaps
- Analysis of negative quantities, zero-priced transactions, and unusual numerical values

## Key Insights

- The United Kingdom generated the highest revenue among the countries analyzed.
- November recorded the highest monthly revenue during the analyzed period.
- A small number of products contributed significantly to total revenue.
- The United Kingdom had the highest number of unique customers.
- The dataset contained negative quantities, zero-priced transactions, missing customer IDs, and unusual numerical values that required investigation.

## Project Files

- `online_retail_eda.html` – Notebook export containing the analysis, Python code, outputs, and visualizations.

## Dataset

The Online Retail dataset contains transaction records with product details, invoice information, quantities, unit prices, customer IDs, transaction dates, and country information.

## Conclusion

This project applied Python-based EDA techniques to analyze retail transactions, understand sales trends, identify top-performing products and countries, examine numerical distributions, and investigate data quality issues to derive meaningful business insights.
